Homelab Kubernetes cluster. OpenTofu provisions the infrastructure, Flux drives everything inside the cluster from git, SOPS and age keep secrets safe in a public repo. Constant attention required. Cooperation not guaranteed.

Stack

Proxmox VE

The one physical host everything runs on.

k3s

Single node, inside a privileged LXC container on Proxmox.

Flux

Bootstrapped against the repo; reconciles everything under kubernetes/.

SOPS + age

Encrypts *.sops.yaml files before they are committed.

cert-manager

Let's Encrypt wildcard certs: one LAN-only, one public.

Traefik

Ingress controller for both LAN and public routes.

OpenTofu

Creates the LXC node and installs k3s; manages Cloudflare DNS and tunnel rules.

Cloudflare Tunnel

Exposes the public apps without opening inbound ports.

Architecture

Repo layout

terraform/
  k3s-cluster/          the LXC node + k3s install
  cloudflare/           DNS records + tunnel ingress rules for public apps
  modules/              reusable modules (public-app-ingress)
kubernetes/
  flux-system/          Flux's own bootstrap manifests
  infrastructure/       HelmReleases: cert-manager, traefik, storage, monitoring
  infrastructure-configs/  CRs that need the charts first (issuers, certs, routes)
  apps/                 workload apps, one directory each
scripts/proxmox-host/   one-off setup scripts run on the Proxmox host
